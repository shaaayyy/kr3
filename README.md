# Тёплый дом — контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

Учебный многостраничный сайт приюта для животных и поиска хозяев. Посетитель может найти питомца, узнать его характер и состояние здоровья, подготовить анкету, выбрать способ помощи и прочитать новости.

Реализация КР №2 создана отдельно от прежнего сайта без CSS-фреймворка. Локальная папка называется `kr2-bootstrap-shop`, как в методичке. По прямому указанию пользователя используется GitHub-репозиторий [shaaayyy/kr3](https://github.com/shaaayyy/kr3), а не рекомендуемое имя `kr2-bootstrap-shop`.

## Запуск

Откройте `index.html` в браузере. Для проверки с локальным HTTP-сервером выполните из корня проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8000. Сборка, npm и backend не нужны.

Bootstrap 5.3.8 подключён через CDN на каждой странице. Версия взята из практической №10; она заменяет 5.3.3 из примеров №9. При ошибке загрузки CDN автоматически используются локальные копии Bootstrap из `vendor/`. Собственные стили подключены после Bootstrap. Фотографии хранятся в `images/`; интернет нужен для карты OpenStreetMap и внешних ссылок.

## Четыре основных раздела

1. **Найти друга** — зелёная главная страница, преимущества, подборка животных, карта и обратная связь справа. Из неё открываются каталог и подробные карточки.
2. **Как забрать домой** — тёплое оформление, этапы усыновления, анкета и FAQ.
3. **Помочь приюту** — синее оформление, демонстрация пожертвования, волонтёрство и помощь вещами.
4. **Новости приюта** — светло-сиреневое оформление и 9 публикаций.

Основное меню содержит ровно четыре пункта. Обязательные по методичке `catalog.html` и `product.html` — внутренние страницы первого раздела. FAQ доступен на странице анкеты и продублирован в каталоге как дополнительный Bootstrap-компонент.

## Практическая работа №9

Тема: Bootstrap-сетка и базовая структура страницы.

- Отдельный проект с `index.html`, `css/custom.css`, `.gitignore` и README.
- Bootstrap CSS и JS Bundle через CDN.
- Синяя шапка, единая адаптивная Bootstrap-навигация и оформленный подвал.
- `container` ограничивает ширину, `container-fluid` оформляет широкую область hero.
- `row`, `col-12`, `col-md-4`, `col-md-6`, `col-lg-4`, `col-lg-6` и `g-*` формируют адаптивную сетку.
- Hero, три преимущества и подборка питомцев вместо товаров из универсального примера.
- Отступы и оформление заданы прежде всего utility-классами Bootstrap.
- Ветка для этой части: `feature/bootstrap-grid-page`.

## Практическая работа №10

Тема: навигация, карточки, кнопки, формы, модальные окна, сообщения и значки.

- `catalog.html`: 6 карточек `card h-100`, изображения, `badge`, кнопки `btn`, информационный `alert`, фильтры и поиск.
- `product.html?id=1`–`6`: сведения о выбранном животном, `breadcrumb`, адаптивная таблица `table-responsive`, `table-striped`, `table-bordered`, переход к анкете.
- `order.html`: `form-control`, `form-select`, `input-group`, `form-check`, обязательные поля, проверка телефона, согласия, кнопка очистки и скачивание TXT.
- Bootstrap `modal` на всех страницах: быстрая заявка на знакомство с выбранным питомцем, поля, согласие и результат.
- Дополнительный компонент — Bootstrap `accordion` с 8 вопросами.
- Мобильное меню, modal и accordion работают через оригинальный Bootstrap JS Bundle.
- `css/custom.css` дополняет Bootstrap: системный шрифт, кадрирование фото, фокус, карта и фиксированная кнопка.
- Ветка для этой части: `feature/bootstrap-components`.

## Доступность и проверка

Tab и Shift+Tab перемещают фокус по ссылкам, кнопкам и полям. Enter активирует ссылки, Enter/Пробел — кнопки. Escape закрывает модальное окно. Bootstrap удерживает фокус внутри modal и возвращает его на открывшую кнопку. Видимая рамка фокуса, подписи полей, alt у фотографий и ссылка пропуска к содержимому сохранены. Кнопки «Наверх страницы» текстовые, учитывают настройку уменьшения движения и переносят фокус в начало страницы.

Статическая проверка файлов, локальных ссылок, идентификаторов и сетки:

```sh
python3 tools/check_project.py
```

Проверка синтаксиса JavaScript при наличии Node.js:

```sh
node --check js/app.js
node --check js/data.js
```

Результаты браузерной проверки приведены в [docs/verification.md](docs/verification.md). Сопоставление с заданиями — в [docs/requirements.md](docs/requirements.md).

## Ограничения учебного проекта

Backend по практической №10 не требуется. Формы ничего не отправляют: заполненные данные обрабатываются только в браузере и скачиваются в TXT. Заявки не сохраняются на сервере. Реальные платежи не принимаются; банковские данные не запрашиваются.

Животные, медицинские сведения, новости, адрес и контакты демонстрационные. Точка на карте условная. Перед реальным запуском нужны настоящие данные приюта и отдельная реализация обработки заявок и платежей.

Третий приложенный документ — практическая №11 по дисциплине «Технологии индустриального программирования» — посвящён указателям C++. Он не задаёт требований к HTML/CSS-сайту и не применяется к интерфейсу.

## Технологии

HTML5, Bootstrap 5.3.8, CSS, JavaScript, Git и GitHub. Системные шрифты Arial/Helvetica. React, Vue, Sass и серверные фреймворки не используются.
