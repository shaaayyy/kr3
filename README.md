# Тёплый дом — КР №2

Учебный сайт приюта на Bootstrap 5.3.8 по практической №9. Реализация создана отдельно от прежнего сайта без CSS-фреймворка.

GitHub-репозиторий `shaaayyy/kr3` выбран пользователем вместо рекомендуемого имени `kr2-bootstrap-shop`.

## Практическая работа 9

Подключены Bootstrap CSS через CDN, Bootstrap JS Bundle и `css/custom.css`. Созданы синяя шапка, адаптивная navbar, hero, три преимущества, сетка трёх питомцев и подвал. Используются `container`, `container-fluid`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*`, отступы и utility-классы Bootstrap. Сохранены карта, контакты и клавиатурная навигация. Фотографии и резервные файлы Bootstrap размещены локально.

Главная проверена на ширинах 375, 768, 1024 и 1440 px; горизонтального переполнения нет. Мобильное меню раскрывается. JavaScript проходит проверку синтаксиса.

## Запуск

Откройте `index.html` либо выполните `python3 -m http.server 8000 --bind 127.0.0.1` и перейдите на http://127.0.0.1:8000.

Ссылки на каталог, анкету, помощь и новости подготовлены для следующей практической №10; страницы добавляются отдельным Pull Request.

## Технологии

HTML, Bootstrap, CSS, JavaScript, Git, GitHub. Backend не используется. Данные и контакты демонстрационные.

## Структура

- index.html — главная
- css/custom.css — минимальные дополнения
- js/ — данные и общая логика
- images/ — фото и логотип
- vendor/ — резервный Bootstrap и лицензия
- docs/sources.md — источники
- .gitignore — исключения Git
