# Тёплый дом — сайт приюта для животных и поиска хозяев

Платформа знакомит будущих хозяев с животными из приюта и помогает выбрать способ поддержки. Основная аудитория — люди, желающие взять питомца или помочь бездомным животным.

## Содержание

- **Каталог животных** — 6 фотографий и индивидуальных описаний, возраст, характер и здоровье; поиск, вид животного и возрастной фильтр.
- **Карточка животного** — подробные сведения, потребности в уходе, условия передачи, кнопки заявки и знакомства.
- **Анкета усыновления** — сведения о будущем хозяине, условиях проживания и опыте, выбранный питомец и согласия.
- **Помощь приюту** — выбор суммы пожертвования, волонтёрство, необходимые вещи и распространение каталога.
- **Контакты** — ссылка в шапке, карта и обратная связь на главной, повтор в футере.
- Дополнительно сохранены 9 новостей и FAQ.

Основное меню содержит 4 пункта: «Каталог животных», «Анкета усыновления», «Помощь приюту», «Новости приюта». Подробная карточка вложена в каталог; контакты доступны из шапки и футера. Главная открывается по логотипу.

## Заявки и пожертвования

Анкета и быстрая заявка проверяют ввод и подготавливают письмо куратору. Посетитель нажимает «Отправить заявку по почте» и самостоятельно подтверждает отправку в почтовой программе. Отдельно можно скачать TXT-копию. Если введённые данные изменены, старые действия скрываются до повторной подготовки заявки.

Выбор суммы пожертвования подготавливает письмо с запросом реквизитов. Деньги не списываются; банковские данные сайт не принимает.

По ответу пользователя контакты оставлены вымышленными: `hello@teply-dom.example`, Telegram `@teply_dom_demo`, телефон и адрес. Поэтому реальная доставка обращений и приём платежей не подключены. Нельзя считать подготовленное письмо отправленной заявкой или выбранную сумму совершённым пожертвованием.

Формы не сохраняют персональные данные на сервере. Для отправки `mailto:` нужна настроенная почтовая программа; скачивание копии работает отдельно от неё.

## Запуск

Откройте `index.html` либо запустите из папки проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Перейдите на http://127.0.0.1:8000. Сборка и npm не требуются.

Bootstrap 5.3.8 подключён на каждой странице через CDN. При недоступности CDN используются резервные локальные файлы из vendor. Собственные стили css/custom.css подключены после Bootstrap. Фотографии лежат в images; карта и внешние ссылки требуют интернета.

## Требования практических работ

Проект создан отдельно от исходной версии без CSS-фреймворка. Локальная папка `kr2-bootstrap-shop` соответствует методичке. Репозиторий [shaaayyy/kr3](https://github.com/shaaayyy/kr3) выбран пользователем вместо рекомендуемого имени.

Практическая №9: Bootstrap-сетка container, container-fluid, row, col-12, col-md-*, col-lg-*, g-*, отступы; главная с hero, преимуществами, подборкой животных и футером.

Практическая №10: многостраничная структура с catalog.html, product.html и order.html; компоненты navbar, card, btn, badge, alert, modal, accordion, breadcrumb, table-responsive и классы форм form-control, form-select, input-group, form-check.

Третий документ, №11, относится к указателям C++, а не к требованиям веб-сайта. Backend, Sass, React/Vue и корзина по приложенным методичкам не требуются.

Соответствие описанию: [docs/project-brief.md](docs/project-brief.md). Подробная матрица заданий: [docs/requirements.md](docs/requirements.md). Фактические проверки: [docs/verification.md](docs/verification.md).

## Интерфейс и доступность

Шапка закреплена; единственный логотип с лапой расположен над меню. Стрелка наверх постоянно видна. Используются мягкие цвета, системные шрифты Arial/Helvetica и небольшие анимации с учётом prefers-reduced-motion.

Tab/Shift+Tab перемещают фокус. Enter активирует ссылки, Enter/Пробел — кнопки. Escape закрывает modal; фокус удерживается внутри окна и возвращается на открывшую его кнопку. Есть подписи полей, alt изображений, видимая рамка фокуса и пропуск к содержимому.

## Проверка

```sh
python3 tools/check_project.py
node --check js/app.js
node --check js/data.js
```

Node нужен только для необязательной проверки синтаксиса. Сайт работает без Node. Проверка адаптивности проводится на 375, 768, 1024 и 1440 px.
