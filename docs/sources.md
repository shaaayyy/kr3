# Источники ресурсов

Bootstrap 5.3.8: https://getbootstrap.com/ — CSS и JS через https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/. Резервные копии в vendor, лицензия MIT сохранена рядом.

Карта: https://www.openstreetmap.org/ — встроенный официальный iframe. Атрибуция авторов OpenStreetMap отображается самим виджетом. Указана условная точка Москвы, а не подтверждённый адрес приюта.

Фотографии: Unsplash. Сохранены локально для учебного макета; изображённые животные не являются подтверждёнными подопечными реального приюта.
