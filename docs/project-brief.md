# Соответствие описанию сайта приюта

Актуальное описание проекта: «Сайт приюта для животных и поиска хозяев». Содержание и действия интерфейса направлены на поиск хозяев и помощь бездомным животным.

| Пункт описания | Где реализован |
| --- | --- |
| Аудитория: желающие взять животное или помочь | На главной два основных пути: каталог животных и помощь приюту |
| Цель: поиск новых хозяев для животных | Главная объясняет путь «выбрать питомца → узнать о нём → подать заявку» |
| Каталог животных | catalog.html: 6 животных, поиск имени, фильтры по виду и возрасту, сброс фильтров |
| Карточка животного | product.html?id=1–6: фотография, описание, возраст, пол, характер, здоровье и условия передачи |
| Анкета для усыновления | order.html?pet=1–6: данные посетителя, условия проживания, опыт, согласия и выбранный питомец |
| Помощь приюту | help.html: пожертвование, волонтёрство, помощь вещами, распространение каталога |
| Контакты | Ссылка в шапке, блок контактов и карта на главной, повтор в футере |
| Фотографии и описания | Локальные фотографии и индивидуальные тексты всех 6 животных |
| Возраст, характер, состояние здоровья | Показаны прямо в карточках каталога; полная информация — на странице животного |
| Заявка на усыновление | Форма проверяет данные и подготавливает письмо с выбранным питомцем. Отправка подтверждается пользователем в почтовой программе. Есть скачивание копии |
| Пожертвование | Выбор суммы и подготовка письма с запросом реквизитов. Перевод денег форма не выполняет |

Контакты и платёжные адреса оставлены вымышленными по прямому ответу пользователя от 12 ноября 2026 года. Поэтому это реализация интерфейса и подготовки обращений, а не действующий приём заявок и денег. На сайте нет ложного сообщения об успешном платеже или доставленной заявке.

## Сохранённые требования предыдущих запросов

В основном меню остаются четыре пункта: каталог, анкета, помощь, новости. Карточка питомца вложена в каталог, контакты доступны отдельно в шапке и на главной. Сохранены раздел «О приюте», FAQ, разные оформления разделов, закреплённая шапка, единственный логотип, постоянная кнопка с логотипом наверх, мягкая палитра, небольшие анимации и клавиатурная навигация.

## Приложенные документы

- Практическая №9: отдельный проект, Bootstrap CDN, container/container-fluid, row, col-*, адаптивные колонки, g-*, hero, преимущества, сетка карточек и футер.
- Практическая №10: отдельные catalog.html, product.html, order.html; общая navbar, card, btn, badge, alert, modal, form-control, form-select, input-group, form-check, accordion, breadcrumb и адаптивная таблица.
- №11 по технологиям индустриального программирования посвящена указателям C++ и не содержит требований к сайту. Она не интерпретируется как инструкция добавлять C++ в интерфейс.
- Backend по практической №10 не требуется. Подготовка письма реализована средствами браузера; сервер и платёжный провайдер не добавлены.

Полная матрица прежних заданий: requirements.md. Результаты проверок: verification.md.
